GRAPHICS PROGRAMMER ENTRY REQUIREMENTS

- Extensive Knowledge of C++
Looking at multiple LinkedIn profiles of technical artists and programmers working in Mojang, one should be familiar and highly competent with using C++ as it is considered the most efficient coding language for graphics rendering.

C++ as a Language:
This coding language is object oriented meaning you can create objects that store data (height, width, etc…) which can be manipulated in code. This makes it an ideal language to use for graphics generation as you can reassign these variables in real time.
C++ compared to other languages is very manual meaning you have to specify everything leading to longer lines of code. For example should you specify a variable as an integer but use it in an equation leading to a double (integers and decimals) datatype variable, it will not return a double variable. For programming graphics, rendering is done in layers and then composited all together in the final composite. This requires multiple optimised classes for efficient graphics generation. Being able to separate variables makes this process much easier.

- Not really an entry level role
Based on a reddit thread the best way to get experience for this role is to do programming for other projects first to show understanding of data structures and algorithms. From there you can start building up to using more modern APIs.

- Key Skills Employers look for:
Maths skills: Nowadays real time graphics are more relevant. Because everything is mostly object oriented, the quickest way to adjust these variables all at once is using maths making this skill essential for instant graphics generation and visualisation.
Because we are working in 3D space, we will be working with matrices as they are able to represent points in 3D space. To manipulate points like these you will need to be able to use vectors.
This article demonstrates the maths behind operations for matrices
Being able to understand how to multiply matrices and vectors together allow you to be able to develop APIs to speed up these processes by turning them into a single function (e.g. Pygame’s draw.lines function which only require the user to state the start and end coordinates, colour and thickness).

Optimisation: As stated before, optimisation is huge for any modern pipeline nowadays. Not only does it cut down on time for rendering, it saves energy cost which allows for resources to be allocated elsewhere. This is especially helpful with the higher level rendering software being used nowadays.
Also being able to understand design for dataclasses will provide a strong base for starting a project in any coding language.

Supporting Software: Whilst knowing C++ is good, being unable to apply this code into an actual program would render this skill useless. Luckily Qt supports C++ and turns the code into an application to be run on various software and hardware platforms. The NCCA PyNGL library is a good example of a supporting library for developing applications to run in programs like Houdini. All that is required is knowledge of python and the properties of the functions in the library which are all provided within the README.md file.

PROGRAMMING ROUTES ROLES

- Software Developer
If you understand how software typically works and how to create applications for them, you’re pretty much ready to create a graphics software of your own.
A graphics software is a computer program used to create and edit images (Adobe Photoshop, Maya, etc.). Normally a program like this requires the ability to read and write files, a way to see in a viewport (sometimes through a camera), a way to adjust viewing position and a way to change the properties of the object or image being manipulated.
Key Skills: Programming Languages, Maths, Optimisation, Software Design, Teamwork

- Graphics Programmer
Someone who focuses on the visual aspects of a game.
Key Skills: C++, Maths, Optimisation, Artistic Eye, Knowledge of Graphics Hardware
What should be demonstrated in your Portfolio: You will be working on VFX, lighting and rendering in this role. To prepare, you should show a strong understanding of real-life physics which can be shown in the form of particle simulations.

- Technical Artist
Similar to a graphics programmer but instead work in more parts of the pipeline. They are responsible for importing assets properly, troubleshooting visual issues, optimise workflows and developing new technologies.
Key Skills: Programming Languages, Modern Animation Software Knowledge, Optimisation
- This is a good example of the skills an aspiring technical artist should display. They provide a range of artistic styles and object manipulation that help build a scene, even providing video showcases.

Upon looking at these routes, I feel I am more likely to go down the path of a graphics programmer. I like the idea of working with other artists and developing special effects with programming. My next steps will be to continue learning C++ and creating projects demonstrating optimised gameplay or simulations with exciting effects.

AI IN PROGRAMMING

This blog discusses the impact of AI on programming jobs and its uses.

“AI-powered tools are becoming more adept at generating code snippets and even entire functions based on natural language descriptions or high-level specifications”. Whilst this is true to a degree, it still is taking examples from multiple different sources and with how open and precise languages can be, it is still a bit difficult to find the exact solution you’re looking for. For example, with the AI summary that now comes with internet searches I was looking for a solution to my html code text not changing to fit my mobile layout the other day however it provided inconsistent solutions which I later had to compare to a forum page discussing the issue. While yes, it provided a similar solution, it was not at all optimised for the scale of my project and provided many unnecessary lines of code. Therefore, should it be used in practice, a professional is still required to keep everything optimised and tidy.

“AI algorithms are becoming increasingly proficient at identifying potential bugs and vulnerabilities in code.” While this statement is most likely discussing cybersecurity it is still important for our code whilst generating graphics to be consistent and stable. The software technical artists develop only need to perform the task they were designed for and only need to be used in one way so it is unnecessary for AI to point out errors when the command terminal can already do that. AI also won’t need to recommend solutions to the issue as a technical artist should be able to spot and fix the issue with their existing knowledge. However, AI could be a useful aid for those still learning and unable to spot their own mistakes.

“Shift in Focus from Writing to Designing” is a good point for the implementation of AI in the pipeline. Having an AI to set up folders with commonly used base files can help speed up the process by a little bit giving artists more time to focus on less mundane tasks.

I don’t see AI replacing many technical artist jobs with how creative the role is. Nowadays people are striving to create something new and unique, something just mashing together already existing ideas couldn’t possibly create to a high standard. It is an artist’s job to create and inspire. We are still needed for our creativity, original ideas and unique perspective.
